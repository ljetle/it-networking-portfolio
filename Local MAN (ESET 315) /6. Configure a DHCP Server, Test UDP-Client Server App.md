# Review Serial Links, Configure a Cisco Router as DHCP Server, and Test the UDP Client/Server Application

## Overview
This lab focused on configuring a network with redundant serial connections between routers to ensure fault tolerance, setting up a Cisco router as a DHCP server, and validating dynamic IP assignment and client-server communication using a custom Python UDP application.

## Objectives
- Configure serial links across Cisco routers to establish redundant network paths.
- Define subnet ranges and IP allocation tables for network devices.
- Configure physical interfaces, VLANs, and default gateways across multiple routers and switches.
- Test network fault tolerance by disconnecting an active serial link to verify path redundancy.
- Configure a Cisco router as a DHCP server to dynamically assign IP configurations.
- Verify dynamic IP assignment across client hosts using command-line diagnostic tools (`ipconfig`).
- Test application-layer communication using Python-based UDP client and server scripts.

## Router & Serial Link Configuration

1. **VLAN Assignment**: Physical ports across switches were grouped into 3 VLANs according to topology requirements.
2. **Interface Configuration**: PuTTY terminal sessions were established to configure Ethernet and Serial interfaces for each router. Note that on the Cisco 3000 series router (Router 2), the Ethernet port designated as `E0` on other routers is designated as `F0/0`.
3. **Redundancy Verification**: After initial ICMP `ping` connectivity was confirmed between PCs, one active serial interface was physically disconnected. Ping continuity tests confirmed that network traffic successfully rerouted through the secondary serial connection.
