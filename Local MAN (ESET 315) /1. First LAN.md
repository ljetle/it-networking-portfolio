# Building a Local Area Network (LAN)

## Overview

This lab was completed as part of ESET 315: Local and Metropolitan Area Networks at Texas A&M University. The objective was to build a basic Local Area Network (LAN) using a router and two host computers, configure IP addressing, and verify connectivity between the hosts.

## Objectives

- Create and test Unshielded Twisted Pair (UTP) Ethernet cables
- Connect two host computers through a router
- Configure router interfaces with IP addresses and subnet masks
- Assign IP addresses to host computers
- Verify network connectivity and inspect the router's routing table

## Network Topology

The network consisted of two host computers connected through a router. Each host was placed on a separate subnet, with the router providing connectivity between the two networks.

## IP Addressing

| Device | Interface | IP Address | Subnet Mask |
|---|---|---|---|
| Router | eth0 | 20.20.40.1 | 255.255.255.0 |
| Host 1 | Ethernet | 20.20.40.2 | 255.255.255.0 |
| Router | eth1 | 30.30.40.1 | 255.255.255.0 |
| Host 2 | Ethernet | 30.30.40.2 | 255.255.255.0 |

## Router Configuration

PuTTY was used to access the router through its console connection. The following commands were used to configure the router interfaces.

```text
enable
configure terminal
interface eth0
ip address 20.20.40.1 255.255.255.0
no shutdown
exit
interface eth1
ip address 30.30.40.1 255.255.255.0
no shutdown
```

## Cable Construction and Testing

UTP Ethernet cables were assembled and tested using a cable tester. The lab also covered the differences between straight-through and crossover cables and their traditional uses when connecting network devices.

## Connectivity Verification

The `ping` command was used to test communication between the two host computers. The `show ip route` command was used to inspect the router's routing table and identify directly connected networks.

| Command | Purpose |
|---|---|
| `ping 30.30.40.2` | Test connectivity from Host 1 to Host 2 |
| `ping 20.20.40.2` | Test connectivity from Host 2 to Host 1 |
| `show ip route` | Inspect the router's routing table |
