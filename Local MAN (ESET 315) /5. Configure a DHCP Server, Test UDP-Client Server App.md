# Serial Link Redundancy, DHCP Server Configuration, and UDP-Client Server Testing

## Overview

This lab focused on three networking tasks: configuring redundant serial connections between routers, setting up a Cisco router as a DHCP server, and testing communication between a Python UDP client and server. The lab also involved subnetting, VLAN configuration, connectivity testing, and troubleshooting network paths.

## Objectives

- Configure serial connections between Cisco routers to provide redundant network paths.
- Calculate subnet ranges and assign IP addresses to network devices.
- Configure router interfaces, VLANs, and default gateways.
- Test network redundancy by disconnecting an active serial link and checking whether traffic reroutes.
- Configure a Cisco router to assign IP addresses dynamically using DHCP.
- Verify host network configurations using `ipconfig`.
- Test application layer communication using Python UDP client and server scripts.

## Python UDP Client/Server Application

Python socket programming was used to test UDP communication over the DHCP-configured network. The application used `SOCK_DGRAM` to send messages between the client and server.

### UDP Server

The server creates an `AF_INET` UDP socket and binds it to IP address `20.20.20.2` on port `15000`. It continuously waits for incoming datagrams, reads the client messages, and sends responses back to the client's address.

### UDP Client

The client creates a UDP socket targeting `20.20.20.2:15000`. It prompts the user for a message, sends the encoded message to the server, and waits for a response. This process repeats three times before the socket closes.

```python
import socket

# Create socket object
s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)

# Set destination port and address
port = 15000
serverAddr = ('20.20.20.2', port)

msg = input("please type your message here-> ")

i = 0
while i < 3:
    print("Sending my message")
    s.sendto(msg.encode(), serverAddr)

    # Receive reply
    msg_rcv, addr = s.recvfrom(1024)
    print("received: " + msg_rcv.decode())
    i += 1

print("closing the socket")
s.close()
```

### Key Takeaways

- DHCP dynamically assigns IP addresses and other network configuration information to client devices.
- UDP allows applications to exchange datagrams without establishing a connection.
- Python's `socket` library supports UDP communication using `AF_INET` and `SOCK_DGRAM`.
- The server listens on a specific IP address and port, while the client sends messages to that destination.
- Receiving and displaying the server's response verifies application-level communication.
