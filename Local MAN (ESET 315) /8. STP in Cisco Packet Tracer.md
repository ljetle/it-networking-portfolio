# Spanning Tree Protocol (IEEE 802.1D) Simulation in Cisco Packet Tracer

## Overview

This lab focused on designing, configuring, and analyzing a switched network using Cisco Packet Tracer. The lab covered VLAN configuration, DNS and HTTP services, Spanning Tree Protocol (STP), network link failures, and the effects of changing link bandwidth on STP path selection.

## Objectives

- Construct a network topology using multiple switches, routers, servers, and PCs.
- Configure IP addressing and host connections.
- Set up DNS and HTTP services.
- Observe STP root bridge elections, port roles, and port states.
- Test STP convergence after a network link failure.
- Modify link bandwidths and analyze their effects on STP path costs.

## Network Topology

The topology contained three interconnected core switches (SW0, SW1, and SW2) forming a redundant loop, along with edge switches, a router, client PCs, a local DNS server, and an external web server.

## Spanning Tree Protocol Configuration

Spanning Tree Protocol (IEEE 802.1D) was used to prevent switching loops in the redundant network topology. STP determines which switch ports forward traffic and which ports are blocked to maintain a loop-free network.

### Initial Topology and Root Bridge Election

Under the initial conditions, the switches used FastEthernet links with an IEEE path cost of 19.

- **Root Bridge:** Switch 1 (SW1) was elected as the root bridge.
- **Blocked Port:** SW2 port `Fa0/3` was placed in an alternate, blocked state to prevent a switching loop.
- **Root Ports:** Non-root switches used root ports to reach SW1.

## STP Convergence During Link Failure

A physical connection between switches was removed to simulate a network link failure.

The observed behavior included:

- STP recalculated the network topology automatically.
- SW1 remained the root bridge.
- A previously blocked alternate path could transition to forwarding to restore connectivity while maintaining a loop-free topology.

## Increased Bandwidth and STP Path Costs

Selected inter-switch connections were upgraded to GigabitEthernet links. The reported IEEE path cost decreased from 19 for FastEthernet links to 4 for GigabitEthernet links.

These changes affected STP path selection and the roles assigned to switch ports.

## Key Takeaways

- STP prevents switching loops by placing redundant switch ports into a blocked state.
- The root bridge election influences path selection throughout the switched network.
- Non-root switches select root ports based on the path cost to the root bridge.
- Higher bandwidth links have lower STP path costs and can change port roles and forwarding paths.
- STP can restore connectivity after an active link fails by allowing an alternate path to forward traffic.
- DNS and HTTP services can be tested through client web browsers to verify name resolution and connectivity.
