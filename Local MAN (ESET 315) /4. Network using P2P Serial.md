# Building a Network Using Point-to-Point Serial Connections

## Overview
This lab focused on building and configuring a network consisting of four routers, four hosts, and two switches. The network used Ethernet connections, point-to-point serial connections with High-Level Data Link Control (HDLC), RIP routing, and VLANs. Connectivity was tested using ping commands, routing tables, and traceroutes.

## Objectives
- Configure router interfaces with IP addresses and subnet masks.
- Configure point-to-point serial connections using HDLC.
- Set clock rates on serial interfaces using the DCE connection.
- Configure RIP routing between routers.
- Assign switch ports to VLANs.
- Test connectivity and analyze packet routes using `ping`, `tracert`, and routing tables.

## Point-to-Point Serial Connections

The serial links between the routers used High-Level Data Link Control (HDLC). Each serial interface needed the correct encapsulation, and the DCE side had to provide the clock rate.

The commands used for serial configuration on the DCE router were:

```text
int serial 0
encapsulation hdlc
ip address 10.10.10.1 255.255.255.0
clock rate 2000000
no shutdown
```

The commands used for serial configuration on the DTE router were:

```text
int serial 0
encapsulation hdlc
ip address 10.10.10.2 255.255.255.0
no shutdown
```

## Connectivity Testing

Connectivity was tested using `ping` and `tracert`. The traceroutes helped identify the path packets followed between hosts and routers.

### Laptop 3 to Laptop 1

The traceroute did not follow the shortest-looking physical path. The report attributed this to Switch 1's VLAN configuration, which prevented ports in VLAN 5 from communicating directly with ports in VLAN 6.

## Key Takeaways
- Point-to-point serial links require proper interface configuration and HDLC encapsulation.
- The DCE side of a serial connection provides the clock rate.
- RIP allows routers to exchange routing information between subnets.
- VLAN assignments determine which switch ports can communicate at Layer 2.
- The physical network layout does not always determine the route packets take.
- Routing tables and traceroutes help explain how traffic travels through a network.
