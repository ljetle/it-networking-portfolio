# Subnetting, Router Configuration, and Packet Analysis

## Overview
This lab focused on configuring a network using three small subnets, two routers, and two hosts. The network used `/30` subnet masks, and connectivity was tested with ping commands. Wireshark was also used to capture and examine network packets.

## Objectives
- Identify subnet numbers and subnet masks.
- Configure router interfaces with IP addresses.
- Configure host IP addresses and default gateways.
- Test connectivity between hosts using `ping`.
- Capture and examine network packets using Wireshark.
- Review router configurations.

## Subnetting

The network used a subnet mask of `255.255.255.252`, equivalent to `/30`. Each subnet contains four total addresses, with two usable host addresses.

| Subnet | Network Address | Subnet Mask |
|---|---|---|
| Subnet 1 | 90.90.90.0/30 | 255.255.255.252 |
| Subnet 2 | 90.90.90.4/30 | 255.255.255.252 |
| Subnet 3 | 90.90.90.8/30 | 255.255.255.252 |

## IP Addressing

| Device | Interface | IP Address | Default Gateway | Subnet |
|---|---|---|---|---|
| Router 1 | E0 | 90.90.90.1 | N/A | 90.90.90.0/30 |

## Key Takeaways
- A `/30` subnet provides four total addresses, including the network and broadcast addresses.
- Router interfaces need IP addresses that belong to their connected subnets.
- Hosts use default gateways to reach devices outside their local subnet.
- Ping tests help verify end-to-end connectivity.
- Wireshark provides a way to capture and inspect network traffic.
- Router configuration screenshots can help document network setup and troubleshooting.
