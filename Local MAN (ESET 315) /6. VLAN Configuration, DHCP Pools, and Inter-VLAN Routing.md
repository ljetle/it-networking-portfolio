# VLAN Configuration, DHCP Pools, and Inter-VLAN Routing

## Overview

This lab focused on configuring VLANs across network switches, creating multiple DHCP pools on a Cisco router, and testing network connectivity between different network segments. The lab also covered RIP routing, DHCP request processing, and trunking behavior between switches.

## Objectives

- Configure VLANs and assign switch ports.
- Configure router interfaces with IP addresses and subnet masks.
- Create multiple DHCP pools for different subnets.
- Configure RIP routing for active network interfaces.
- Examine DHCP requests and trunking behavior across inter-switch connections.
- Verify configurations using Cisco IOS commands.

## Network Topology

The network used Cisco routers, switches, and connected laptops. Router 1 provided two Ethernet interfaces for the `20.20.20.0/24` and `30.30.30.0/24` networks. The switches used VLAN assignments to separate devices into different network segments.

## DHCP Pool Configuration

Router 1 was configured with two DHCP pools to provide addressing information for different subnets.

### Fall

- Network: `30.30.30.0/24`
- Default gateway: `30.30.30.1`
- DNS servers: `30.30.30.5` and `30.30.30.6`

### Jet

- Network: `20.20.20.0/24`
- Default gateway: `20.20.20.1`

## Router Configuration

The `show running-config` command was used to review Router 1's interface addresses, DHCP pools, and RIP configuration.

```text
hostname Router

ip dhcp pool Fall
 network 30.30.30.0 255.255.255.0
 default-router 30.30.30.1
 dns-server 30.30.30.5 30.30.30.6

ip dhcp pool Jet
 network 20.20.20.0 255.255.255.0
 default-router 20.20.20.1

interface Ethernet0
 ip address 30.30.30.1 255.255.255.0

interface Ethernet1
 ip address 20.20.20.1 255.255.255.0

interface Serial0
 no ip address
 shutdown
 no fair-queue

interface Serial1
 no ip address
 shutdown

router rip
 network 20.0.0.0
 network 30.0.0.0

ip http server
ip classless
```

The serial interfaces were shut down and did not have IP addresses assigned in the captured configuration.

## RIP Routing

Routing Information Protocol (RIP) was configured to advertise the networks connected to Router 1.

```text
router rip
 network 20.0.0.0
 network 30.0.0.0
```

The configuration included the `20.0.0.0` and `30.0.0.0` networks.

## DHCP Testing and Troubleshooting

### Dynamic IP Acquisition Across Switches

The lab examined how a connected laptop could receive an IP address from the DHCP server when connected through the switches.
The lab report attributed successful DHCP assignment to the crossover cable connecting the switches, which allowed traffic from VLAN 2 and VLAN 3 to cross between them.

### DHCP Request Processing

DHCP requests were described as being processed according to the VLAN the requesting host was connected to.

Potential issues included:
- Improperly connected physical cables.
- Incorrect VLAN assignments.
- Required VLANs not being allowed across inter-switch trunk links.
  
## Key Takeaways
- VLANs separate switch ports into different broadcast domains.
- Multiple DHCP pools can provide addressing information for different subnets.
- RIP allows routers to exchange routing information for configured networks.
- VLAN assignments affect which devices can communicate at Layer 2.
- Inter-switch connections must carry the necessary VLAN traffic for communication between network segments.
- Commands such as show vlan and show running-config help verify network configurations.
