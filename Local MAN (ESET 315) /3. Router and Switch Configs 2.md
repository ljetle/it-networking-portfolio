# RIP Routing and VLAN Configuration

## Overview

This lab was completed as part of ESET 315: Local and Metropolitan Area Networks at Texas A&M University. The objective was to configure a network consisting of two routers, a switch, and two host computers. The lab focused on IPv4 addressing, Routing Information Protocol (RIP), VLAN configuration, and network connectivity testing.

## Objectives

- Configure router interfaces with IPv4 addresses and subnet masks
- Configure RIP routing between two routers
- Assign switch ports to specific VLANs
- Configure host IP addresses and default gateways
- Verify VLAN assignments and interface status
- Test end-to-end connectivity using `ping` and `tracert`

## Network Topology

The network consisted of two routers connecting two separate host subnets through an intermediate network. A switch was configured with multiple VLANs to logically separate devices.

## VLAN Configuration

The switch ports were assigned to VLANs to separate devices into logical groups.

| Switch Port | VLAN ID | VLAN Name |
|---|---:|---|
| Fa0/1 | 2 | VLAN 2 Group 28 |
| Fa0/3 | 2 | VLAN 2 Group 28 |
| Fa0/5 | 3 | VLAN 3 Group 28 |
| Fa0/7 | 3 | VLAN 3 Group 28 |
| Fa0/9 | 4 | VLAN 4 Group 28 |
| Fa0/11 | 4 | VLAN 4 Group 28 |

The following commands were used to assign switch ports to VLANs:

```text
en
conf t
int fa0/1
switchport access vlan 2
int fa0/3
switchport access vlan 2
int fa0/5
switchport access vlan 3
int fa0/7
switchport access vlan 3
int fa0/9
switchport access vlan 4
int fa0/11
switchport access vlan 4
```

## Router Configuration

### Router 1

The first router was configured with interfaces for the `10.10.10.0/24` host subnet and the `30.30.30.0/24` inter-router network.

```text
en
conf t
int e0
ip address 10.10.10.1 255.255.255.0
no shutdown
int e1
ip address 30.30.30.1 255.255.255.0
no shutdown
router rip
network 10.10.10.0
network 30.30.30.0
```

### Router 2

The second router was configured with interfaces for the `30.30.30.0/24` inter-router network and the `50.50.50.0/24` host subnet.

```text
en
conf t
int g0/0/0
ip address 30.30.30.2 255.255.255.0
no shutdown
interface g0/0/1
ip address 50.50.50.1 255.255.255.0
no shutdown
router rip
network 30.30.30.0
network 50.50.50.0
```

## Verification and Testing

The network was tested using Cisco command-line tools and host command prompts.

| Command | Purpose |
|---|---|
| `show vlan` | View VLAN IDs, names, status, and assigned switch ports |
| `show interfaces` | Inspect interface status and details |
| `ping` | Test connectivity between hosts |
| `tracert` | Identify the path taken between hosts |

### Connectivity Results

The report recorded three hops between Host A and Host B:

1. `10.10.10.1`
2. `30.30.30.2`
3. `50.50.50.2`
